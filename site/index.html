Ask in a room

Someone describes a change in an Agora room and a task card is proposed.

A worker builds it

A coding worker makes the smallest change that does the job and opens a pull request.

A reviewer checks it

The reviewer only blocks on points that were written in the task notes.

Confirmed and live

Once merged, GitHub Pages publishes the page and this list grows by one line.
